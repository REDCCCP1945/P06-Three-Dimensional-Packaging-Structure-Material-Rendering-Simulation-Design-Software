# 三维包装结构与材质渲染仿真设计软件 V1.0.0

- 著作权人：陕西理工大学
- 版本：V1.0.0
- 技术栈：Node.js 标准库 + 浏览器 Canvas
- 运行方式：本地单机，默认端口 4106

## 目录结构

```
server.js          HTTP 服务、路由、鉴权与限流
lib/               服务端模块（存储、认证、盒型、刀版、评估、版本等）
public/            控制台与共享预览页面（HTML / CSS / JS）
package.json       运行配置
```

## 启动

```bash
node server.js
```

启动后访问 `http://127.0.0.1:4106`。首次启动会在 `data/` 下生成业务样本与令牌密钥；可通过环境变量 `PORT` 与 `DATA_DIR` 指定端口与数据目录。

## 能力边界

本软件以 Canvas 二维投影绘制三维盒体，提供参数化刀版、BOM 计算与环保评分，不包含 Three.js、WebGL 2.0、PBR 材质、法线贴图、环境反射与阴影贴图；不含多租户与 Redis 缓存。软件为设计与预览工具，不替代专业 CAD 与生产刀版。
